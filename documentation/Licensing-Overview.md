# Licensing Summary

## Sketchfab
- Free models: Check individual model license (CC0, CC-BY, Standard)

- Free tier: 100 credits/month — personal/evaluation only

## Hyper3D
- Free tier: Limited credits — personal use
- Paid plans: Commercial licensing, API access, high-resolution exports
