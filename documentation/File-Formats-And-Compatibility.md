# Supported File Formats & Compatibility

## Model Formats
- FBX — Unity, Unreal, Blender, Maya, 3ds Max
- OBJ — Blender, Maya, 3ds Max, Unity
- GLB/glTF — Web, Blender, Unity, Unreal, Godot, AR/VR
- STL — 3D printing (Cura, Prusa, Simplify3D)
- USDZ — Apple AR Quick Look
- 3MF — 3D manufacturing format
- BLEND — Blender native

## Texture Formats
- PNG, JPG — PBR material maps (albedo, normal, roughness, metalness, AO)

## Animation Support
- FBX — embedded skeletal animation
- GLB — embedded keyframe/bone animation
