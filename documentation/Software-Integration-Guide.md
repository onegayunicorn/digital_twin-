# Software Integration Guide

## Game Engines
- **Unity**: Import FBX/GLB → animations preserve → use Meshy/Hyper3D plugins
- **Unreal Engine**: Import FBX → skeletal animation retargeting supported
- **Godot**: Drag-and-drop GLB → animation plays natively

## DCC Tools
- **Blender**: Install Meshy/Hyper3D plugin → direct export/import → one-click animation
- **Maya/3ds Max**: FBX exchange → full animation and rig compatibility

## AR/VR
- **WebXR**: Use GLB → view in browser → Sketchfab VR button
- **Apple Vision Pro**: Export USDZ → AR Quick Look
- **Oculus/HTC Vive**: Run standalone builds or view via Sketchfab VR
