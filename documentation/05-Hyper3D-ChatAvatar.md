# Hyper3D — ChatAvatar
- **Function**: Generate animatable 3D faces/avatars from text prompts
- **Technology**: Based on SIGGRAPH award-winning research (CLAY/CAST)
- **Output**: Fully rigged, animatable 3D head/face models
- **Use Cases**: Virtual avatars, game characters, VR/AR, digital humans
- **URL**: https://hyper3d.ai/workspace/chatavatar
