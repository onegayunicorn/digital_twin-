## Safety boundary

The BCI layer is a non-medical, simulation-only device abstraction. It must not emit stimulation, infer diagnoses, make treatment recommendations, control vehicles/weapons, or expose arbitrary hardware commands. Real-device support, if later requested, must remain read-only and require a separately reviewed connector, explicit user consent, vendor SDK compliance, and clinician oversight for any health-related use.
